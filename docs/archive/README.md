# 归档文档

本目录保存历史审阅、过程验证和周报类材料。它们可用于追溯项目演进，但不再作为当前设计或交付判断的优先入口。

当前根目录保留的主线文档包括：

- `FeishuProject.md`：赛题原文和最终交付要求。
- `README.md`：项目现状、运行提示和文档导航。
- `FeishuAgent 阶段任务规划.md`：阶段划分与验收标准。
- `阶段3审阅设计文档.md`：阶段 3 文档收敛、实现差距和下一步目标。
- `概要设计说明书+FeishuAPI.md`、`架构设计说明书.md`、`对象模型与模块设计说明.md`、`模块接口文档.md`：当前目标设计。
- `OpenClaw主体化方案.md`、`WorkItem Hub 归属边界条件设计.md`：当前专项设计基线。

归档原则：

- 历史审阅报告保留问题背景，但若与当前实现冲突，以根目录主线文档为准。
- 本地联调记录只做追溯，不作为架构事实来源。
- 周报类材料不参与评审交付包，只在需要回看阶段进展时参考。
